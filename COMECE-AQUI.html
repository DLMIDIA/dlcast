macOS

Tudo o que é do Mac está na pasta mac
  1. Abra a pasta mac
  2. Clique duas vezes em DLCast.command
  3. O painel abre sozinho no navegador
Abrir instruções do Mac
Não precisa instalar nada. O servidor já vem dentro da pasta, nas versões para Apple Silicon e Intel — o sistema escolhe a certa sozinho.

Para desligar depois, clique duas vezes em mac/DESLIGAR.command.
🪟

Windows

Tudo o que é do Windows está na pasta windows
  1. Abra a pasta windows
  2. Clique duas vezes em DLCast.bat
  3. Quando o Windows perguntar, marque Redes particulares e permita
  4. Pronto — o endereço aparece na tela
Abrir instruções do Windows
Não precisa instalar nada. O servidor já vem pronto dentro da pasta.

só macOS só Windows compartilhado
Por que dividir assim? Cada sistema tem seu jeito de executar programas — o Mac usa .command, o Windows usa .bat. Já a configuração, o painel e a documentação são idênticos nos dois, então ficam em pastas compartilhadas. Assim não existe arquivo duplicado, e você sabe na hora onde mexer.

Antes do primeiro voo

Os dois erros que travam todo mundo:

1. O microfone. A partir do DJI Fly v1.16.0, o controle RC 2 exige um microfone conectado no USB-C. Sem ele, o botão de iniciar transmissão simplesmente não responde — e não aparece mensagem de erro nenhuma explicando isso.

2. A rede. O controle precisa estar no mesmo Wi-Fi que o computador. Lembre que o drone não fala com o computador: quem envia o vídeo pela rede é o controle.
