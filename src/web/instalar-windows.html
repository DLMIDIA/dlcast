Instalação no Windows

Passo a passo completo. Os arquivos já vêm na pasta — você não precisa caçar download em site nenhum.

Leva cerca de 5 minutos

Preciso configurar alguma coisa dentro dos programas?

Não. Nenhum dos programas tem tela de configuração para você mexer. O MediaMTX não abre janela — ele lê o arquivo de configuração que já vem pronto dentro do DLCast, com tudo ajustado.

Na prática você faz três coisas: copiar um arquivo para a pasta certa, dar um clique duplo e autorizar o firewall na primeira vez. Só isso.

1
Abra a pasta windows
obrigatório · 10 segundos

Dentro da pasta do DLCast existe uma pasta chamada windows. Tudo o que o Windows precisa está lá dentro — inclusive o servidor, já baixado e pronto.

Você não precisa copiar, instalar nem configurar nada. É só abrir essa pasta.

DLCast\
├── COMECE-AQUI.html
├── config\
├── src\
├── mac\ ← ignore, é do Mac
└── windows\ ← abra esta
    ├── DLCast.bat ← o clique duplo é aqui
    ├── mediamtx.exe
    └── LEIA-ME.txt
Recomendado
Use o arquivo da pasta
Versão 1.20.0, a mesma que foi testada com o drone neste projeto. Já está baixada e pronta.
Ou baixe a versão mais nova
Se preferir a última versão publicada. Baixe o arquivo terminado em windows_amd64.zip e descompacte.
Abrir página oficial
A versão que vem na pasta é a estável testada. Versões mais novas costumam funcionar, mas só a 1.20.0 foi validada em voo real com o DJI Air 3.
2
Ligue o servidor
obrigatório · 10 segundos

Dentro da pasta windows, dê um clique duplo no arquivo DLCast.bat.

Vai abrir uma janela preta com o endereço do seu servidor escrito nela. Essa janela precisa ficar aberta enquanto você usa — é o servidor rodando. Para desligar, é só fechá-la.

O Windows vai perguntar sobre o firewall. Aparece uma janela azul perguntando se o programa pode aceitar conexões.

Marque "Redes particulares" e clique em Permitir acesso.

Se você clicar em cancelar, o drone não vai conseguir se conectar e o erro não deixa pista nenhuma — é o problema número 1 no Windows.
3
Configure o drone
obrigatório · 2 minutos

A janela preta mostra um endereço parecido com este: 

rtmp://192.168.1.100:1935/drone

Digite esse endereço no DJI Fly, em Transmissão → Plataformas de Transmissão ao Vivo → RTMP.

Não esqueça o microfone. A partir do DJI Fly v1.16.0, o controle RC 2 exige um microfone conectado no USB-C para deixar iniciar a transmissão. Sem ele, o botão simplesmente não responde.
4
FFmpeg
opcional · só se quiser retransmitir

Pule este passo se você só quer receber e gravar o vídeo do drone. O sistema funciona completo sem o FFmpeg: recebe, grava, e você assiste no painel.

O FFmpeg só é necessário para duas coisas:

Retransmitir para YouTube, Facebook, Twitch
Gerar vídeo de teste sem usar o drone

Não incluímos ele na pasta porque ocupa mais de 100 MB — deixaria o DLCast quatro vezes maior por um recurso que muita gente não usa.

Mais fácil
Pelo winget
Abra o PowerShell e rode este comando. O Windows baixa e instala sozinho. 
winget install Gyan.FFmpeg
Ou baixe manualmente
Baixe, descompacte e adicione a pasta bin ao PATH do Windows.
Abrir site oficial
5
Python
opcional · só para o painel visual

O painel com vídeo ao vivo e estatísticas precisa do Python para funcionar. O servidor em si não precisa — o drone transmite e grava normalmente sem ele. 

winget install Python.Python.3.12
Se você não quiser instalar o Python, ainda dá para assistir ao vídeo abrindo direto no navegador o endereço que a janela preta mostra, na porta 8889.

Resumo do que é obrigatório

ProgramaTamanhoPrecisa?Para quê
MediaMTX 53 MB Sim É o servidor. Já vem na pasta.
FFmpeg ~100 MB Não Só para retransmitir ao YouTube
Python ~25 MB Não Só para o painel visual
Ou seja: para receber o vídeo do drone e gravar, basta um arquivo que já está na pasta. O resto é conforto.

Se der problema

O drone diz "falha ao conectar"

Quase sempre é o firewall. Vá em Configurações do Windows → Firewall → Permitir um aplicativo, e confirme que o mediamtx.exe está liberado em "Particular". Verifique também se o controle está no mesmo Wi-Fi que o computador.

A janela preta abre e fecha na hora

Significa que a pasta está incompleta — normalmente o mediamtx.exe foi apagado, ou a pasta windows foi separada do resto do projeto. Copie a pasta DLCast inteira de novo.

O botão de transmitir não funciona no controle

É o microfone. O DJI Fly v1.16.0+ exige um conectado no USB-C do RC 2.
